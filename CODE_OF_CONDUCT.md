# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. Everyone participating in the project, in issues, pull requests and discussions, is expected to follow it.

## Enforcement

To report unacceptable behavior, contact the maintainers through GitHub: open a private [security advisory](https://github.com/netglance/wireguard-split-tunnel/security/advisories/new) or contact the owners of the [netglance](https://github.com/netglance) organization. Reports are handled privately.
